# 睡岗检测阈值矩阵测试模板

> 用途:模型到位后,按"3 档持续时长 × 3 档俯角阈值 × 3 类样本"定稿 `thresholdMs` / `headPitchThresholdDeg` 参数。
> 跑法:对每行执行 `DURATION_MS=<时长> PITCH_DEG=<角度> bash scripts/sleep_post_test.sh <样本文件>`
> 判定:睡岗样本应"触发";低头工作/弯腰取物样本应"不触发"。误报(该不报却报)与漏报(该报却不报)都要记录。

## 一、样本清单(由 AI 算法角色提供,建议 ≥30s 各一段)

| 样本类型 | 文件名 | 内容要求 |
|---|---|---|
| 睡岗 | `sleep_case.mp4` | 工位人员持续低头/趴桌 ≥8s |
| 正常低头工作 | `work_bow.mp4` | 低头看键盘/文件,单次 ≤2s 或断续低头 |
| 弯腰取物 | `pick_up.mp4` | 弯腰捡东西、喝水、仰头等干扰动作 |
