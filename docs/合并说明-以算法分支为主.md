## 二、对外接口(以算法分支为主,唯一口径)

- 算法 code:`on_yolo11n_pose`;模型 `/opt/SVA/models/yolo11n-pose.onnx`(letterbox 灰边114、RGB、640)
- 事件类型:`sleep` → 后端 `SVA_SLEEP`/`睡岗告警`(白名单放行 sleep)
- 规则:behaviorRules `behaviorType:"sleep"` + `hdThreshold`(默认 0.12,别名 thetaHd/theta_hd)+ `thresholdMs`(持续时长,演示建议 2000/真实建议 8000)+ 区域/静止等既有字段
- 布控算法选择:av_algorithm `on_yolopose_sleep`(睡岗检测(姿态关键点),已入库 id=19)
- 模型缺失:启动仅告警不崩溃(本次收敛增强),睡岗算法不可用时任务按"不支持的算法"跳过
