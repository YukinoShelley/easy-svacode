   # 输出:收流端口=41238;code=0 alive=3 track数=2;ffmpeg 拉流 frame=...;✅ PASS

## 三、验收前必办清单(按依赖排序,标负责人)

1. **[组长/流媒体] SIP 方案裁定**:WVP 外置(推荐,资料最全)还是 ZLM 内实现;裁定后按 `docs/GB28181接入/` 部署 WVP 并注册一台模拟国标设备(开源模拟器不在仓库,见 P0 验证手册 §6 引用)。
2. **[流媒体/后端] 通道列表来源收口**:WVP 侧提供通道(推荐)或扩展 ZLM gb API;同步后 `UPDATE zlm_server SET gb28181_enabled=1, gb_sip_port=5060 WHERE id=1`;加 sys_job 30s 同步任务。
3. **[后端] 国标流 URL 形态收口**并注入布控(streamUrl),供验收 ③ 拉流。
4. **[后端+前端] 上下线状态联调与页面**:`/gb/notify`/轮询 → h_device.is_online → 页面"在线/离线"。

## 四、演示脚本(供验收当天,前置=第 1/2 项完成)

```bash
# A. 媒体层自证(无真机,可随时跑):预期 PASS
bash tools/gb28181/verify_zlm_gb28181.sh
# B. 平台可见国标设备(模拟器注册后):
#    设备管理页 → GB28181 类型 → "从流媒体同步"按钮;或
curl -X POST http://127.0.0.1:9114/waring/device/gb/import -H "Authorization: Bearer $TOKEN" -d '{"deviceType":"GB28181"}'
# C. 国标布控 + 预览:建布控(deviceType=GB28181)→ 详情页视频预览 → 分析器 /api/health 帧计数增长
# D. 上下线:拔掉/停模拟器 → 页面状态 30s 内变"离线";恢复 → 变"在线"
# E. 睡岗闭环(可选叠加):国标设备 + 睡岗布控 → 睡岗告警 SVA_SLEEP(验收点4)
```
