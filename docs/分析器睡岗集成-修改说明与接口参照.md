## 一、本阶段做了什么(一句话)

把 YOLO-Pose 睡岗检测以**纯增量**方式接入 SVA-server:新增关键点解码器 + 俯角几何 + 时序判定规则 `sleep_post`,全部复用现有布控/告警/推流/上报链路;**现有代码行零修改**(仅一处 swapRB 表达式的等价泛化),缺模型可正常启动,老算法零回归。

## 三、相关接口(对外契约,后端/前端/AI 角色据此对接)

### 1. 布控下发 JSON(经现有 `POST :9993/api/control/add`,无新路由)

```json
{
  "code": "布控编号",
  "streamUrl": "rtsp://...",
  "algorithmTasks": [
    { "algorithmCode": "on_yolo11n_pose_sleep", "objectCodes": ["person"],
      "detectFps": 8, "scoreThreshold": 0.5, "nmsThreshold": 0.5 }
  ],
  "regions": [{ "id": "region_1", "primary": true, "points": [0,0,1,0,1,1,0,1] }],
  "geometryConfig": {
    "behaviorRules": [{
      "id": "sleep_rule_1", "name": "睡岗检测",
      "customEventName": "睡岗", "behaviorType": "sleep_post",
      "enabled": true, "geometryId": "region_1",
      "thresholdMs": 5000, "headPitchThresholdDeg": 60,
      "ruleObjectCode": "person"
    }]
  }
}
```

- `behaviorType="sleep_post"`(白名单外的**新类型**,分析器在规范化后补救识别);
- `headPitchThresholdDeg` 为新增可选规则字段(别名 `pitchThresholdDeg`),缺省 60°;`thresholdMs` 缺省 5000ms(联调建议档位 3000/4000/5000);
- 静止约束可选:`maxSpeedPxPerSec > 0` 时要求目标静止(默认不约束)。

### 2. 事件与告警(完全复用现有链路,分析器侧零新增上报代码)

- 命中后 `DetectFrameEvent` 携带 `behaviorType="sleep_post"`、`customEventName="睡岗"`、`ruleId`、`regionId/regionName`、`trackId`;
- 后续:WS detect.event → 后端建 h_waring → 回拨 `/api/alarm/bind-media` → 分析器生成截图/录像 → 回调 `addFromSvaMediaCallback`(**需后端先补映射,见 docs/后端sleep_post映射需求单.md**)。

### 3. 模型契约(AI 算法角色导出时核对)

| 项 | 约定 |
|---|---|
| 模型文件 | `yolo11n_pose_sleep.onnx`,放置 `/opt/SVA/models`(root),重启分析器生效 |
| 输出形状 | `1×56×N`:cx,cy,w,h + person 类分 + 17×(x,y,conf)(与 ultralytics Pose 头一致) |
| 输入 | 640×640 方形 pad、RGB(BGR→RGB,即 profile `square_rgb`) |
| 类别 | 仅 person(id 0);objectness 阈值 0.5、NMS 0.5(引擎内置,与老 Dense 一致) |
| 验收标志 | 分析器日志出现 `decoder=dense_pose_with_nms` 且无 `睡岗模型加载失败` |

| 契约项 | 原值 | 对齐后 | 说明 |
|---|---|---|---|
| 算法 code | `on_yolo11n_pose_sleep` | **`on_yolo11n_pose`(规范)+ 别名 `on_yolopose_sleep`(后端 av_algorithm 种子)+ 历史名** | resolveAlgorithm/profile 全认 |
| 模型文件 | `yolo11n_pose_sleep.onnx` | **`yolo11n-pose.onnx` 优先,旧名兜底**(/opt/SVA/models) | AI 角色产出文件名 |
| 预处理 | 方形黑边 0 | **letterbox 灰边 114(居中,RGB)** | AI 角色 Python 验证口径,勿回退 |
| 张量读取 | row-major 步长 56 | **channel-major `pdata[c*N+a]`**(标准 ultralytics (1,56,N) 导出) | 修正潜在误读 bug |
| 规则判据 | 仅俯角(pitch≥60°) | **默认 hd 判据(头肩距离比 ≤0.12,A(角色验证口径));可选 pitch 判据(headPitchThresholdDeg>0)** | 规则 JSON 新增 `hdThreshold`(别名 thetaHd/theta_hd) |

| 后端映射 | — | 仍缺(backend 分支未加);建议按需求单补 `sleep_post`(可复用 SVA_SLEEP/睡岗告警常量,见 algorithm 分支补丁样式) | 阻塞项未变 |
| GB28181 线 | 零代码 | 不变(媒体侧契约:分析器按后端注入 streamUrl 拉流,`live/` 与 `rtp/` 形态待后端收口) | 参考 G28181国标接入 分支工具做 B4 验证 |
