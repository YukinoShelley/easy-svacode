# easySVA 项目内容介绍

> 本文档面向课程展示与小组文档，介绍二次开发所基于的开源项目 easySVA 的整体内容。

---

## 一、项目简介

**easySVA（easy Surveillance Video Analytics）** 是一款面向中小企业的**轻量化分布式 AI 视频分析系统**，主要应用于安全生产场景（厂区、矿井等）的视频智能监控。系统基于若依（RuoYi）前后端分离框架开发，AI 分析器采用 C++ 实现，支持大模型对告警结果进行复核，整体架构清晰、代码规范，适合作为学习视频分析技术的入门项目。

**核心能力**：接入摄像头视频流 → AI 目标检测与行为分析 → 异常事件告警（截图+录像）→ 大模型复核降误报 → 前端大屏展示与处置闭环。

## 二、系统组成（五大仓库）

| 仓库 | 技术栈 | 职责定位 |
|---|---|---|
| **SVA-backend** | Java 17 + Spring Boot 4.0.3（若依 RuoYi 3.9.1） | 系统后台：用户权限、设备管理、算法配置、布控任务、告警记录、AI 复核调度 |
| **SVA-web** | Vue 2.6 + Element UI + ECharts + flv.js | 系统前端：登录、首页看板、设备管理、视频预览、布控配置、事件编排、告警查询、大屏展示 |
| **SVA-server** | C++17 + CMake（FFmpeg + OpenCV + ONNX Runtime） | AI 分析器：视频流拉取解码、YOLO 目标检测、行为分析、告警视频生成、结果推流 |
| **SVA-mediaServer** | C++（ZLMediaKit 魔改版） | 流媒体服务器：设备流代理接入、分发播放、时移告警录像、视频拼接电视墙 |
| **easySVA** | Shell + SQL | 总装仓库：一键编译安装脚本、完整数据库 SQL |

## 三、系统架构与数据流

```
摄像头(RTSP/GB28181)
      │ 拉流/注册
      ▼
SVA-mediaServer (ZLMediaKit :9992/9994)
      │ 播放地址分发         ▲ 算法流推流
      ▼                     │
SVA-server (C++ 分析器 :9993) ── 检测/行为分析 ──→ 告警事件
      │ 告警上报(HTTP/WS)
      ▼
SVA-backend (Spring Boot :9114) ── 存库/AI复核 ──→ MySQL
      ▲
      │ REST / WebSocket
SVA-web (Vue + nginx :80)  ← 用户操作/视频预览/告警展示
```

**完整业务闭环**：
1. 添加设备（RTSP 直连或国标接入），绑定流媒体/分析节点
2. 创建**布控任务**：选择设备 + AI 算法 + 检测目标 + 绘制区域/线段 + 配置行为规则（跨线、进区、停留、睡岗等）
3. 分析器对视频流逐帧检测推理，命中规则后触发告警：抓拍截图 + 生成告警视频（时移录像）
4. 告警入库后由**大模型复核**（通义千问 VL 等多模态模型）判定真警/误报
5. 前端实时视频预览（带检测框叠加）、告警查询、整改处置闭环、大屏展示

## 四、核心功能模块

### 1. 设备管理
- 设备类型：RTSP 主动拉流；GB28181 国标设备（本项目扩展目标）
- 设备在线/离线状态监控，绑定流媒体服务器与分析服务器

### 2. AI 算法与布控
- 内置 YOLO 系列检测模型（80 类通用目标、矿井 8 类专用目标等），ONNX Runtime 推理（TensorRT/CUDA/CPU 自动选择）
- **17 种行为规则**：跨线、进区、出区、停留、低速、徘徊、躺卧、缺席、数量阈值、占用、定向/逆向通行、接近/远离、打架等
- 支持多算法并行、多阶段行为序列编排、检测帧率/置信度/NMS 阈值可调

### 3. 告警闭环
- 告警截图 + 告警视频（媒体服务器时移录制：告警前 N 秒回溯 + 告警后 N 秒续录）
- 告警等级、类型、组织归属管理；整改处置（责令整改）；误报处理
- **AI 大模型复核**：多模态模型看图判定 true_alarm / false_alarm / uncertain，输出置信度与原因摘要

### 4. 流媒体能力（SVA-mediaServer 魔改）
- 设备流代理接入与 ws-flv/RTSP 分发播放
- 时移告警录像接口（startRecordTask + back_ms/forward_ms）
- 视频拼接电视墙（多路合成一路 1080p 流，支持动态切换）
- 流回放控制（暂停/倍速/seek）

### 5. 大屏与看板
- 首页看板（隐患统计/分布/趋势）、调度大屏（实时告警、告警排行、监控点状态）

## 六、本项目（课程）的两大增量开发

### 任务一：GB28181 国标设备接入
在原有 RTSP 主动拉流基础上，扩展支持国标 GB/T 28181 摄像头**主动注册接入**（SIP 信令 + RTP 推流），覆盖设备注册、保活、离线管理、设备列表同步、统一布控与预览。

### 任务二：睡岗行为检测算法
基于 **YOLO-Pose 人体关键点检测**开发工位睡岗检测：识别头部姿态角度 + 多帧时序判断（过滤瞬时低头），导出 ONNX 集成进 C++ 推理管线，新增"睡岗告警"类型，打通布控配置 → 告警截图 → 存库 → 前端展示全链路。
