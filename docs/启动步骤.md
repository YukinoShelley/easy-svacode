# easySVA 启动/关闭/运维指南

> 适用：通过仓库内 `setup.sh` 一键搭建完成的系统（Ubuntu 22.04）
> 默认账号：admin / admin123 · 访问地址：http://<本机IP>/（用 `ip addr` 查看当前 IP）
> 开发模式：克隆目录即开发仓库（软链接部署），见 README 第三节

---

## 一、组件总览

| 组件 | 角色 | 端口 | 启动方式 |
|---|---|---|---|
| MariaDB | 数据库（easySVA 库，42 表） | 3306 | 系统服务 |
| Redis | 缓存/会话 | 6379 | 系统服务 |
| SVA-backend | Java 后台（Spring Boot 3/若依） | 9114 | rc.local 或 start.sh |
| ZLMediaKit | 流媒体服务器 | 9992(HTTP) 9994(RTSP) 9995(RTMP) | rc.local 或 start.sh |
| SVA-server | C++ AI 分析器 | 9991(admin) 9993(推理) | rc.local 或 start.sh |
| Nginx | 前端页面 + 反向代理 | 80 | 系统服务 |
| mediamtx（可选） | 虚拟摄像头测试流 | 8554 | start.sh（未安装自动跳过） |

**依赖关系**：MySQL/Redis → 后端 → ZLM → 分析器。

## 二、启动服务

```bash
# 方式一：一键启动（推荐）
sudo <克隆目录>/scripts/start.sh start

# 方式二：模拟开机（执行 rc.local 内容）
sudo bash /etc/rc.local

# 方式三：重启系统（rc.local 自动拉起全部服务）
```

验证：

```bash
ss -tlnp | grep -E '9114|9992|9993'      # 三端口监听即成功
curl -X POST http://127.0.0.1/prod-api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'   # 返回 {"code":200,"token":...}
```

## 三、使用流程

1. 浏览器打开 `http://<本机IP>/`，admin / admin123 登录；
2. 设备管理 → 添加设备（类型 `DIRECT`，URL 填 RTSP/HLS；测试流见 `docs/Vstream.txt`）→ 启动监控 → 预览可播放；
3. 布控管理 → 新建布控（选设备、算法如 `yolo26s_80类目标检测`、画布控区域）→ 启动；
4. 布控详情页/视频墙可播放算法画框输出流（h264+aac）；
5. 分析器确认：`curl http://127.0.0.1:9993/api/health` 中 `detectFrameSent` 持续增长。

## 四、关闭服务

```bash
sudo <克隆目录>/scripts/start.sh stop
# 系统服务（MariaDB/Redis/Nginx）如需停止：
sudo systemctl stop nginx redis-server mariadb
```

## 五、开发模式（改代码即生效）

部署位置（/opt/SVA/*、/var/www/SVA-web/dist）为指向克隆目录的软链接：

```bash
# 改完代码后重新编译对应组件，再重启：
sudo <克隆目录>/scripts/start.sh restart
```

各组件编译命令见 README 第三节。**克隆目录勿删除/移动**（重跑 setup.sh 可恢复）。

## 六、关键文件位置

| 文件 | 用途 |
|---|---|
| `/opt/SVA/backend/backend.jar` | 后端（软链接 → 克隆目录产物） |
| `/opt/SVA/server/Analyzer` | 分析器（软链接 → 克隆目录产物） |
| `/opt/SVA/mediaServer/MediaServer` + config.ini | ZLMediaKit |
| `/opt/SVA/config.json` | 分析器配置（host 已写本机 IP） |
| `/opt/SVA/models/` | YOLO 模型（yolo11n / yolo26s / 矿井） |
| `/var/www/SVA-web/dist` | 前端页面（软链接 → 克隆目录产物） |
| `/var/www/SVA-web/upload/` | 上传文件（alarm/、storage/） |
| `/etc/nginx/sites-enabled/default` | Nginx：`/prod-api/` `/websocket/` 代理 |
| `/etc/rc.local` | 开机自启 |
| 克隆目录 `SVA-backend/.../application-druid.yml` | 数据库连接配置（改库密码需重新打包） |

## 七、日志与排障

```bash
tail -f /opt/SVA/backend/run.log       # 后端日志
tail -f /opt/SVA/server/log.out        # 分析器日志
tail -f /opt/SVA/mediaServer/zlm.log   # ZLM 日志
```

| 问题 | 处理 |
|---|---|
| 后端起不来 | MySQL/Redis 是否运行；密码 `easySVA.EZ` |
| 页面打不开 | `ip addr` 看当前 IP（DHCP 会变）；`nginx -t` |
| 预览黑屏 | 设备「启动监控」成功？ZLM 9992 通？ |
| 分析器不处理 | `curl http://127.0.0.1:9993/api/health` 看帧计数；布控需处于运行中（服务重启后需重新"启动布控"） |
| 前端 404 | 克隆目录是否被移动/删除（软链接断）；家目录权限（setup.sh 已自动处理） |
