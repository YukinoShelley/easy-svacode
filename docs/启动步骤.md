# easySVA 启动/关闭指南

> 环境：Ubuntu 22.04（本机 10.21.224.107）· 项目源码在 `/home/jun/桌面/easySVA/`
> 默认账号：admin / admin123 · 访问地址：http://10.21.224.107/
> **管理方式：nohup 后台进程，无开机自启，重启后需手动 `./start.sh start`**

---

## 一、组件总览（6 个组件 + 可选虚拟摄像头）

| 组件 | 角色 | 端口 | 启动方式 |
|---|---|---|---|
| MariaDB | 数据库（easySVA 库，42 表） | 3306 | `systemctl start mariadb`（系统服务） |
| Redis | 缓存/会话 | 6379 | `systemctl start redis-server`（系统服务） |
| SVA-backend | Java 后台（Spring Boot 3/若依） | 9114 | `start.sh` 内 nohup 启动（`java -jar backend.jar`） |
| ZLMediaKit | 流媒体服务器（拉流/转码/分发） | 9992(HTTP) 9994(RTSP) | `start.sh` 内 nohup 启动（`./MediaServer -d -c config.ini`） |
| SVA-server | C++ AI 分析器（FFmpeg+OpenCV+ONNX YOLO） | 9993(推理) | `start.sh` 内 nohup 启动（`./Analyzer -f config.json`） |
| Nginx | 前端页面 + 反向代理 | 80 | `systemctl start nginx`（系统服务） |
| mediamtx（可选） | 虚拟摄像头（RTSP 测试流） | 8554 | `start.sh` 内 nohup 启动 |

**依赖关系**：MySQL/Redis → 后端 → ZLM → 分析器；Nginx 最后起也行（只服务页面）。

**最省事：全部组件一条命令**
```bash
sudo /home/jun/桌面/easySVA/start.sh start
```

## 二、启动步骤（按顺序执行，或直接用 start.sh）

### 第 1 步：数据库和缓存
```bash
sudo systemctl start mariadb redis-server
# 验证
mysql -uroot -peasySVA.EZ easySVA -e "SHOW TABLES;" | head -3
```

### 第 2 步：后端（Java）
```bash
cd /opt/SVA/backend
nohup java -jar backend.jar > run.log 2>&1 &
# 等 30~60 秒（Spring Boot 启动），验证：
ss -tlnp | grep 9114          # 看到 LISTEN 即成功
curl http://127.0.0.1/prod-api/login -X POST -H 'Content-Type: application/json' -d '{"username":"admin","password":"admin123"}'
# 返回 {"code":200,"token":"..."} 即成功
```

### 第 3 步：ZLMediaKit 流媒体
```bash
cd /opt/SVA/mediaServer
nohup ./MediaServer -d -c /opt/SVA/mediaServer/config.ini > zlm.log 2>&1 &
# 验证：
ss -tlnp | grep -E '9992|9994'
curl -s "http://127.0.0.1:9992/index/api/getServerConfig" -d 'secret=V3522025zlm0aA9ajn7UiOWi' | head -c 100
```

### 第 4 步：AI 分析器（C++）
```bash
cd /opt/SVA/server
nohup ./Analyzer -f /opt/SVA/config.json > log.out 2>&1 &
# 验证：
curl -s http://127.0.0.1:9993/api/health | head -c 200
# 应返回 {"code":1000,"metrics":{...}}
```

### 第 5 步：前端页面
```bash
sudo systemctl start nginx
# 浏览器打开 http://10.21.224.107/ ，admin / admin123 登录
```

### 第 6 步（可选）：虚拟摄像头（无真实摄像头时用于测试）
```bash
cd /opt/sva-test && nohup ./mediamtx mediamtx.yml > mediamtx.log 2>&1 &
nohup /usr/local/ffmpeg/bin/ffmpeg -re -stream_loop -1 -i /root/dsh/downloads/sintel.mp4 \
  -c:v libx264 -preset ultrafast -tune zerolatency -c:a aac -listen 1 \
  -f rtsp -rtsp_transport tcp rtsp://127.0.0.1:8554/test > /opt/sva-test/teststream.log 2>&1 &
# 视频源：rtsp://127.0.0.1:8554/test（mediamtx + ffmpeg 循环推流测试视频）
# 验证：
ffprobe -rtsp_transport tcp -v error rtsp://127.0.0.1:8554/test 2>&1 | head -2
```

## 四、关闭步骤（逆序）

```bash
# 方式一（推荐）：一键停止
sudo /home/jun/桌面/easySVA/start.sh stop

# 方式二（手动）：
# 1. 分析器 → ZLM → 后端
pkill -f 'Analyzer -f /opt/SVA/config.json'
pkill -f 'MediaServer -c /opt/SVA/mediaServer/config.ini'
pkill -f 'java -jar /opt/SVA/backend/backend.jar'
# 2. 虚拟摄像头
pkill -f mediamtx; pkill -f sintel.mp4
# 3. 前端（可选）
sudo systemctl stop nginx
# 4. 数据库/缓存（可选）
sudo systemctl stop redis-server mariadb
```


## 六、关键配置文件位置

| 文件 | 用途 |
|---|---|
| `/opt/SVA/config.json` | 分析器配置（IP/端口/模型目录/告警上报地址） |
| `/opt/SVA/mediaServer/config.ini` | ZLM 配置（secret、端口） |
| `/opt/SVA/backend/backend.jar` | 后端（配置内嵌：DB 密码 easySVA.EZ、端口 9114） |
| `/home/jun/桌面/easySVA/SVA-backend/ruoyi-admin/src/main/resources/application-druid.yml` | 数据库连接配置（改库密码需重新打包） |
| `/etc/nginx/sites-enabled/default` | 前端站点 + `/prod-api/` `/websocket/` `/zlm/` 代理 |
| `/opt/SVA/models/` | YOLO 模型（yolo11n / yolo26s / 矿井模型） |

## 七、常见问题

- **后端起不来**：确认 MySQL/Redis 已启动、端口 3306 密码为 `easySVA.EZ`
- **预览黑屏**：确认设备「启动监控」成功、ZLM 9992 端口通、虚拟摄像头（或真实相机）在线
- **分析器连不上**：`config.json` 里 `host` 要改成当前机器 IP（现为 10.21.224.107）
- **前端接口 404**：Nginx 需配置 `/prod-api/` 代理到 9114（已配好，勿删）
- **重启后系统全没了**：正常现象（无开机自启），执行 `sudo ./start.sh start` 即可
