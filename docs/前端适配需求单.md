## A. 设备管理(验收点3-②③④ 页面层)

| # | 需求 | 说明 | 接口 | 涉及文件 |
|---|---|---|---|---|
| A1 | 设备类型标签 | 列表显示 RTSP/GB28181 类型标签;类型用字典 `sva_device_type` 渲染(勿硬编码) | 字典接口 | `src/views/device/manage.vue` |
| A2 | 添加设备支持 GB28181 | "设备类型"目前只有 DIRECT/PLATFORM;增加 GB28181 选项,选中后出现国标字段:`gb_device_id`(20 位国标编码,必填)、`gb_platform_id`(可选) | `POST /waring/device`(后端已按 device_type 校验) | `manage.vue` |
| A3 | "从流媒体同步国标设备"按钮 | 设备列表工具栏按钮 → 弹窗列出远端通道(勾选)→ 一键导入;另提供"状态同步"按钮 | `GET /waring/device/gb/remote-channels`、`POST /waring/device/gb/import`、`POST /waring/device/gb/status/sync` | `manage.vue` + `src/api/device.js` 新增封装 |
| A4 | 国标设备预览 | GB 设备行内"预览"按钮可播(ws-flv);播放地址形态以后端/流媒体收口为准(暂定 `ws://{zlm}:9992/live/{gb_id}.live.flv`,后端另有 `/live/gb/{apeId}` 接口),**先按后端返回地址接** | `GET /waring/device/live/gb/{apeId}` 或 h_device.play_url | `manage.vue` + 现有预览组件 |
| A5 | 上下线状态刷新 | 验收 3-④:国标设备离线/上线后列表状态列能更新;后端同步完成后前端刷新或定时刷新即可,可加"刷新"按钮 | 现有列表接口 | `manage.vue` |
| A6 | 国标字段展示 | 列表/详情显示 gb_device_id、SIP 平台信息 | — | `manage.vue` |

## B. 布控管理(验收点2/4 页面层)

## D. 接口封装建议(api 层)

在 `src/api/device.js` 新增:

```js
export function gbRemoteChannels()          { return request({ url: '/waring/device/gb/remote-channels', method: 'get' }) }
export function gbImport(data)              { return request({ url: '/waring/device/gb/import', method: 'post', data }) }
export function gbStatusSync()              { return request({ url: '/waring/device/gb/status/sync', method: 'post' }) }
export function gbLiveUrl(apeId)            { return request({ url: `/waring/device/live/gb/${apeId}`, method: 'get' }) }
```

## E. 验收口径提示

- 页面能"看到国标设备"(A2/A3 导入后列表出现)、"能预览"(A4)、"状态同步"(A5)→ 验收点 3 页面层;
- 布控能选到睡岗并配规则(B1/B2)→ 验收点 2/4 页面层;
- 告警列表出现"睡岗告警"(C1)→ 验收点 4 展示层。
- 注意:国标全链路依赖 SIP/通道来源收口(见 `docs/项目实现缺口清单.md`),前端可先用 curl/后端联调先行开发,再用页面验收。
